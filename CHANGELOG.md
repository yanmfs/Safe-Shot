# Changelog

## 0.1.0

- First release: local OCR, detectors for Brazilian documents and other sensitive data, QR code and barcode detection, solid redaction bars, PNG and JPEG export, post-export verification, global shortcut that opens the clipboard image, queue of several images, macOS menu bar with Open, Save, Undo and Redo, system text reader (Vision, Windows OCR) with Tesseract as a fallback, personal always-hide terms, Portuguese and English.
